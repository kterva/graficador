📚 Centro de Ayuda

Guía completa del Graficador

¿Qué puedes hacer?

  • 📈 Graficar datos experimentales con barras de error (Δx, Δy)
  • 📐 Ajustes de regresión: lineal, polinomial, exponencial, logarítmica, potencial
  • 🔬 Análisis de incertidumbre: cálculo automático de pendientes máxima/mínima (método de extremos)
  • 🎨 Personalización completa: títulos, etiquetas, límites de ejes, colores
  • 💾 Exportación: PNG, PDF y proyectos guardables

🎯 Primeros Pasos

1. Ingresa tus datos

Completa la tabla con valores de X e Y. Opcionalmente agrega incertidumbres (ΔX, ΔY).

2. Selecciona el tipo de ajuste

Elige entre: Lineal, Cuadrática, Exponencial, Logarítmica o Potencial.

3. Visualización Automática

¡Listo! Verás tu gráfica actualizada en tiempo real conforme ingresas los datos.

💡 Tip: Usa los botones de "Datos de Prueba" (en develop) para cargar ejemplos rápidamente.

🛠️ Herramientas y Utilidades

📊 Funciones de Gráfica

📉 Tangente (Derivada)

Activa "Mostrar Tangente" y mueve el slider para ver la línea tangente y su pendiente en cualquier punto.

∫ Área (Integral)

Activa "Mostrar Área" y define un intervalo [x₁, x₂] para calcular el área bajo la curva.

🔍 Zoom y Pan

Usa la rueda del mouse para zoom y arrastra para mover. Tip: Si haces zoom o arrastras directamente sobre los números de un eje (X o Y), modificarás únicamente ese eje de forma independiente. Doble clic para restablecer.

💾 Guardar y Cargar Proyectos

Permite guardar todo tu trabajo actual (datos, configuraciones, títulos) para continuarlo después.

  • Formato: Archivo .json (Texto plano estandarizado).
  • ¿Qué guarda?: Series de datos completas, etiquetas de ejes, títulos y configuraciones visuales.
  • Uso: Botón "Guardar" para descargar y "Cargar" para restaurar.
📤 Exportación de Imagen

Descarga tu gráfica en PNG o PDF para informes.

💡 Consejos y Trucos

✅ Mejores prácticas:
  • Usa al menos 5 puntos para ajustes confiables
  • Verifica que R² esté cerca de 1 para buen ajuste
  • Agrega incertidumbres para análisis más precisos
⚠️ Errores comunes:
  • Elegir tipo de ajuste incorrecto (ej: lineal para datos cuadráticos)
  • Datos con valores negativos en ajustes logarítmicos/potenciales
  • Muy pocos puntos para ajustes complejos
🎨 Personalización:

Usa el panel "Configuración de Gráfica" para cambiar títulos, etiquetas de ejes y límites.

⌨️ Atajos rápidos:
  • Scroll central: Zoom in/out en ambos ejes
  • Scroll sobre un eje: Zoom solo en ese eje
  • Arrastrar un eje: Mover solo ese eje
  • Arrastrar centro: Mover toda la gráfica
  • Doble clic: Restablecer zoom
